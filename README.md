# AI Lawyer / Memory Support — Concept Stub

This repository currently contains a short project description only; it does not contain an application implementation.

The description in this repository is about caregiver-supported memory-story sessions, not legal advice or legal case prediction. The name is historical and can be confusing.

## Related prototype repositories

- [NeuroEase](https://github.com/nikhil-247/NeuroEase): front-end UI prototype using sample data. It is not connected to a backend, AI provider, audio service, or persistent storage.
- [AI-Lawyer-](https://github.com/nikhil-247/AI-Lawyer-): separate Express/MongoDB and Python story-service experiment. It is not integrated with the NeuroEase UI and is not ready for real patient data; its README documents current security limitations.

Neither linked repository should be presented as a production healthcare product or as a validated therapy system. Do not use real patient data in these prototypes.

## Next step

Use the NeuroEase UI repository as the design prototype and decide explicitly whether to continue integrating the separate backend experiment. Once the project scope is confirmed, this concept stub can be archived or turned into a proper implementation repository.
